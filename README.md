# Ahmad's Dungeon

Puzzle and combat game in C++ on AlphaEngine. The player controls 2 characters to
solve puzzles, unlock paths and fight monsters through to a boss fight. Team of 4.

## My role (tool developer)
- 6 screens: main menu, pause, win, lose, credits, level editor page
- Level editor
